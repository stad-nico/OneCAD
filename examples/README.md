# OpenTSCAD Examples

This directory contains example projects showcasing different use cases and capabilities of OpenTSCAD. Each example is a complete, self-contained project that demonstrates specific features or techniques.

## Available Examples

### 1. **mechanical-parts** - Functional Mechanical Components
Complex mechanical parts with proper tolerances, fits, and assemblies.
- **Features**: Parametric design, engineering tolerances, assembly modeling
- **Complexity**: Intermediate to Advanced
- **Use Cases**: 3D printing, mechanical engineering, prototyping

### 2. **architectural-elements** - Building and Structural Components  
Architectural elements like stairs, railings, and structural components.
- **Features**: Large-scale modeling, construction techniques, building codes
- **Complexity**: Intermediate
- **Use Cases**: Architecture, construction, scale models

### 3. **artistic-sculptures** - Creative and Artistic Models
Abstract and artistic 3D sculptures demonstrating creative possibilities.
- **Features**: Complex geometries, artistic forms, mathematical patterns
- **Complexity**: Beginner to Advanced
- **Use Cases**: Art, decoration, creative expression

### 4. **miniatures-gaming** - Gaming Miniatures and Terrain
Miniature figures and gaming terrain for tabletop games.
- **Features**: Detailed modeling, gaming specifications, terrain generation
- **Complexity**: Intermediate
- **Use Cases**: Gaming, miniatures, terrain modeling

### 5. **educational-models** - Learning and Teaching Tools
Educational models for STEM learning and demonstration.
- **Features**: Clear explanations, progressive complexity, scientific accuracy
- **Complexity**: Beginner to Intermediate  
- **Use Cases**: Education, teaching, learning

## Getting Started with Examples

### Quick Start
```bash
# Clone or download an example
cd examples/mechanical-parts

# Install dependencies  
npm install

# Start development
npm run dev
```

### Exploring Examples

Each example includes:
- **README.md**: Detailed explanation and learning objectives
- **models/**: Source TypeScript model files
- **docs/**: Additional documentation and images
- **package.json**: Dependencies and scripts
- **screenshots/**: Visual previews of the models

### Learning Path

**Recommended progression:**

1. **Start with educational-models**: Learn basic concepts
2. **Try artistic-sculptures**: Explore creative possibilities  
3. **Move to mechanical-parts**: Apply engineering principles
4. **Advance to architectural-elements**: Scale up to larger projects
5. **Create miniatures-gaming**: Focus on detailed work
