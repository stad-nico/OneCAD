# {{projectName}}

A basic OpenTSCAD project for getting started with 3D modeling.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open your browser to see the 3D model
4. Edit `models/simple.ts` to modify your model
